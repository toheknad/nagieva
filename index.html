01

«Окна»

Сапёр родом из Windows — то есть прямиком из «Окон». Учимся открывать их правильно: первый клик, пустые зоны, каскады.

02

«Кухня»

Готовим паттерны по рецептам: 1-2-1, 1-2-2-1 и другие блюда, после которых поле разминируется за секунды.

03

«Физрук»

Ставим руку: скорость, чординг и ноль лишних движений. Гоняем, пока таймер не начнёт тебя уважать.
